# SAVVA site — manual deploy archive

Deploy-ready static site archive.

Vercel manual deployment:
1. Create a new Vercel project.
2. Upload this folder/archive.
3. Framework preset: Other / Static.
4. Build command: leave empty.
5. Output directory: leave empty because index.html is at the archive root.

Hosting files are at the root: index.html, styles.css, script.js, favicon.svg, assets/.
PRODUCT.md and DESIGN.md are included only as project context.
